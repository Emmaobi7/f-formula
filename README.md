# The Flirt Blueprint / The F-Formula

An editorial luxury redesign for **The Flirt Blueprint / The F-Formula** — a relationship education brand.

## Key Features & Structure

- **Editorial Luxury Aesthetic**: Warm ivory canvas (`#FAF7F2`), near-black charcoal typography (`#181514`), deep wine / burgundy accent (`#581C26`), and muted rose undertones.
- **Typography Hierarchy**: `Cormorant Garamond` (Display Serif) + `Plus Jakarta Sans` (UI & Body Sans-Serif).
- **Asymmetrical Hero & Cinematic Video**: Custom player modal with responsive controls.
- **Section 2 — The Shift**: Intellectual pivot on conversational navigation vs. scripts.
- **Section 3 — The Framework**: 3-movement progression track with oversized serif numerals and fine-line axis.
- **Section 4 — The Woman Behind The Method**: Founder profile with portrait framing.
- **Section 5 — The Experience**: Magazine-style testimonial spread.
- **Section 6 — Inside The F-Formula**: Editorial table of contents and tactile clothbound mockup.
- **Section 7 — The Bonuses**: Catalogue stack of included companion resources.
- **Section 8 — The Offer**: High-contrast dark charcoal decision block ($47 one-time investment).
- **Section 9 — The Guarantee**: 60-day reassurance section with typographic seal.
- **Section 10 — FAQ**: Accessible editorial accordion.
- **Section 11 — The Final Invitation**: Narrative closure with hero callback.
- **Section 12 — Site Footer**: Magazine colophon and navigation landmarks.

## Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
